## Requirements 
- `pip install -r requirements.txt` to install the necessary packages
- Download the state dictionary files from (here)[] and save to the `/data/` folder. Then, execute `python create-models.py` to create the fine tuned models
- Last you'll need a (Genius API key)[https://genius.com/api-clients]

## Running the app

`python app.py` to start the web interface
